# Wii U Notes
## Unsupported Javascript
- `let` and `const`
- Backticks (`)
- Lambda/Arrow functions
- `fetch`
- `for of` loop
- Array's `forEach` (and probably other array functions)

## Unsupported CSS
- Any kind of viewport units (vw, vh, vmax, vmin)
- RGBA colors
- Some properties (namely `transition` and `transform`) require the `-webkit-*` prefix
